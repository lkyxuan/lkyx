# 个人 harness 的设计

- 目标：提出任何产品想法时，Agent 不直接开写，先搜现成开源方案再决定复用 / 改造 / 自研。
- 调研结论：
  - Superpowers：一组 Claude Code skills，覆盖头脑风暴、写计划、TDD、子 agent 开发。形式和我们想要的一致，直接作为依赖使用，不重造。
  - Spec Kit / OpenSpec：规格驱动开发，偏正规流程、较重。个人快速迭代暂不用，项目做大时再按项目单独引入。
  - 三者都没有"先搜开源"这一步，所以自己写 `prior-art-first` 补上。
- 关键决定：
  - 形式：GitHub 仓库 + Claude Code 插件，用户级安装一次全局生效，不做 App。
  - 主导权：`lkyx-workflow` 规定顺序，Superpowers 只在大项目时执行其中几步。
  - 顺序：先澄清再搜索（需求清楚了才搜得准），搜索后再计划。
  - 暂不加 hook：先看 skill 自动触发的效果，经常被跳过时再加。
- 后续：实际用几个项目后，根据跳步、太重等问题调整两个 skill。

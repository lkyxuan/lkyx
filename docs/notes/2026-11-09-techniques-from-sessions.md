范围：2026-11-02 ~ 2026-11-09 的 Claude Code 会话。跳过了只有标题的「Miracle的Mac mini」空会话、修图 / 视频 / 写作 / 取名这类非开发会话。本周开发类会话主要是 Mac mini 运维（密码管理、浏览器、MCP 清理、mstack 安装）、Kiki App 连接排查和 GitHub 主页。

## 升级为正式技巧

### dev-techniques #4 远程干活，先确认在哪台机器、用户在不在跟前（新增，置信度 0.7）
- 2026-11-07，「GitHub 主页展示优化」：任务跑在了错误的机器上，用户说「不是 Mac mini 在执行，是 MacBook 吗？切换一下」。
- 2026-11-08 ~ 09，「本地密码管理器」：Agent 打开的 Chrome 在 MacBook Pro 上而不是 Mac mini 上，用户说「我在 mac 前面 没有」「这个 chrome 打开的是我 MacBook pro 上的」；Agent 登录网站时为了密码卡在本机授权弹窗，用户说「他为了密码就卡住了」「我不会在那个远程 Mac 跟前的，就是我完全不知道他在找我，这就是问题」，最后改为让 Agent 优先用服务账号读密码。
